AI-Orchestrated Docs.
Human-Orchestrated Comments.

Docs live directly in your repository, and comments live as a native layer on top, never locked in third-party SaaS silos. AI agents orchestrate the documentation as code evolves, while humans orchestrate the reviews and discussions on rendered views.

The Problem

SaaS Tools Trap Knowledge in Silos

External tools like Notion or Confluence isolate comments from your codebase. Human feedback gets trapped in closed SaaS silos instead of living with your docs source.

AI Orchestrated

AI Agents Orchestrate Your Docs

Markdown files in your repository serve as native, indexable context for AI agents. As code and architecture change, AI assistants (Cursor, Copilot, Claude) can inspect, query, generate, and continuously update the raw documentation in Git.

Human Orchestrated

Humans Orchestrate the Comments

Humans review rendered visual variants with rich inline feedback and discussion threads. Comments are saved directly to Git via custom refs as a lightweight layer on top, giving teams instant review loops without pull requests or commit noise.

Clean Source Branches.
Zero-Overhead Custom Refs.

Isolated Ref Namespace

Standard Git branches live under refs/heads/ and tags under refs/tags/. By isolating comments in refs/md-comments/, discussion data is stored in Git without polluting your branch list, commit logs, or PR diffs.

Zero Commits & Zero PR Overhead

Standard Git porcelain commands (checkout, diff, status) ignore custom refs. Teams can post, reply, and resolve discussions instantly via API without triggering CI/CD pipelines or merge conflicts.

Cryptographic Integrity & Rollbacks

Comments are anchored with commit SHAs and FNV-1a content hashing. When checking out historical commits or rolling back files, comments stay preserved across Git history while inline annotations re-anchor accurately.

Plain HTML & Generic JS Embed

Add collaborative inline comments to any website or static HTML page with a single script tag. Zero dependencies or complex build setup required.

HTML Embed Snippet 
<!-- Drop Markdown Comments into any HTML document -->
<script
  src="https://unpkg.com/@md-comments/embed/dist/md-comments.min.js"
  data-repo="owner/repo"
  data-file="docs/architecture.md"
  async>
</script>
  • Works with any static site, Hugo, Jekyll, custom Markdown or plain HTML.
  • Automatic selection popup, margin pins, and GitHub OAuth Device Flow.
  • Full two-way sync with GitHub Extension, VS Code, Cursor, and Obsidian.
