# Website Assets

This folder contains media assets for the Markdown Comments static website.

## Screenshots Directory

Place real screenshot files in `website/assets/screenshots/`:

- `vscode-sidebar.png` / `vscode-sidebar.jpg` - Screenshot of the VS Code extension side panel in action.
- `obsidian-sidebar.png` / `obsidian-sidebar.jpg` - Screenshot of the Obsidian plugin comments sidebar.
- `github-tab.png` / `github-tab.jpg` - Screenshot of the Chrome Extension's GitHub Pull Request comments tab.
- `github-inline.png` / `github-inline.jpg` - Screenshot of the inline comment thread on a GitHub file diff page.

The website CSS is designed to automatically render rich mockups if the image files are not present, making it fully functional and aesthetically pleasing as a template out-of-the-box.
