# Markdown Comments Example

This sample document demonstrates inline commenting in the Markdown preview.

## Quick Start

Run npm install to get started. Clone the repository and open this folder in Cursor.

## Configuration

Comments use your GitHub username when you are signed in to GitHub in the editor or your repo’s `origin` points at GitHub.

## Next steps

Open the preview to the side, select a sentence, and add a comment. The companion file `example.comments.yml` will be created or updated next to this file.
