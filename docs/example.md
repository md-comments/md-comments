# Markdown Comments Example

> **AI-Orchestrated Docs. Human-Orchestrated Comments.**  
> Docs live directly in your repository, and comments live as a native layer on top, never locked in third-party SaaS silos. AI agents orchestrate the documentation as code evolves, while humans orchestrate the reviews and discussions on rendered views.

This sample document demonstrates leaving inline discussions directly on rendered documentation views without polluting source Markdown files.

## Quick Start

1. Open this file in **VS Code**, **Cursor**, or **Antigravity**.
2. Open the **Comment Preview** side panel (`Cmd/Ctrl+Shift+P` → `Markdown Comments: Open Comment Preview`).
3. Select any sentence in this document and click **Add comment**.

## How It Works

- **Zero Inline HTML Tags**: The markdown in `docs/example.md` stays 100% clean for AI coding assistants and static site generators.
- **Git Ref Storage**: All threads and reactions save to `refs/md-comments/data` with zero commits and zero branch clutter.
- **Rendered View Collaboration**: Comments appear across IDEs, documentation portals (Astro / Starlight), Obsidian, and GitHub PR reviews.
