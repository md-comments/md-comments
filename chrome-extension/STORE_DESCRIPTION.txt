Markdown Comments is a privacy-first browser extension that enables seamless collaboration on Markdown documentation directly inside GitHub.

It bridges the gap in documentation reviews by allowing you to highlight text, start nested discussion threads, tag teammates with @mention autocomplete, and leave emoji reactions—all powered by the GitHub backend with zero-commit overhead on your main branch.

When tagging collaborators, Markdown Comments automatically triggers native GitHub notifications (Web inbox bell, GitHub Mobile push, and email) by attaching commit comments directly to the data reference, requiring zero external notification servers or third-party webhooks.

With no databases or external servers, your conversations remain fully version-controlled, secure, and synced alongside your codebase, featuring a dedicated workspace tab, conventional commit formatting, protected branch support, and robust fuzzy anchoring to keep comment positions accurate as files evolve.
